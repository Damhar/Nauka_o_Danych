# Laboratorium 3 — Wizualizacja danych (wariant 14)

Laboratorium z przedmiotu **Nauka o Danych I**, wykonane w Pythonie i Jupyter Notebook na zbiorze IHME USA Risk Spending 2016.

## Pliki w repozytorium

- [Notebook źródłowy](NOD1_Lab3_Wariant14.ipynb)
- [Dane CSV](IHME_USA_RISK_SPENDING_2016_Y2020M09D29.csv)
- [Sprawozdanie w formacie Markdown](Sprawozdanie_Lab3_Wariant14.md)

## Zakres

- Matplotlib: wykres liniowy, słupkowy, histogram, kołowy, punktowy, 3D, siatka, adnotacje.
- Plotly: wykresy interaktywne, 3D, subploty i mapy.
- plotnine: wykresy warstwowe, linia trendu, facetowanie, box plot, motywy.
- Eksploracja danych: porównania kategorii ryzyka, przyczyn i rozkładu wydatków.

## Uruchamianie

W katalogu z notebookiem:

```powershell
py -m pip install notebook pandas numpy matplotlib plotly plotnine
py -m notebook
```

Otwórz `NOD1_Lab3_Wariant14.ipynb` i wybierz **Run → Run All Cells**.

**Uwaga:** zbiór danych obejmuje całe USA i nie zawiera danych dla poszczególnych stanów ani współrzędnych. Mapy wymagające takich danych są przykładami demonstracyjnymi.
